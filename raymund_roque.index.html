GitHub Pages Deployment Guide

Host your live VA portfolio web app for free

Step 1: Create a GitHub Repository

Log into GitHub.com, click New Repository, name it va-portfolio, and keep it Public.

Step 2: Initialize Git & Push Code

git init

git add .

git commit -m "Initial commit for Raymund Roque VA Portfolio"

git branch -M main

git remote add origin https://github.com/YOUR_USERNAME/va-portfolio.git

git push -u origin main

Step 3: Enable GitHub Pages

  1. Go to your repository settings tab on GitHub.
  2. Click Pages on the left sidebar under "Code and automation".
  3. Under Build and deployment -> Branch, select main and click Save.

Your live portfolio URL will be:

https://YOUR_USERNAME.github.io/va-portfolio/
